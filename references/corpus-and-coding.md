# 语料构建与叙事编码

## 1. 明确推断对象与材料边界

记录研究对象、平台或媒体、时间区间、语言、文本体裁、AI 指称范围与纳排规则。区分生成式 AI、具体产品、一般人工智能以及模糊“智能化”；混用时说明理由。

建立检索式与检索日志，保留来源 URL/文档标识、发表时间和采集时间。搜索引擎结果只能视为发现渠道，不能默认构成代表性抽样框。说明付费墙、删除、排序和平台访问造成的缺失。

原文与清洗文本分别保存。区分重复、转载、引用链与相似文本：若研究内容分布，可去重或分层；若研究传播路径，转载关系就是数据。记录处理规则，不悄悄改变计数分母。

区分抽样单位（文章/帖子）、编码单位（段落/命题/叙事片段）和语境单位（全文/讨论串）。一篇文章含多个说话者，不应因引述他人观点便判定媒体赞同。标题、正文、配图和评论若同时分析，分别注明；多模态判断须基于实际可见材料。

比较媒体、企业和公众时，交代各自选样机制、体裁、时期与数量差异；便利评论样本不能外推“公众普遍认为”。涉及访谈或私人材料时，沿用研究者的同意与匿名化安排，只处理任务必要信息。

## 2. 方法选择

| 目标 | 合适路径 | 主要质量依据 |
| --- | --- | --- |
| 比较叙事特征的分布、来源或时期差异 | 定量内容分析 | 可操作编码规则、抽样边界、合适的一致性评估 |
| 理解共享意义与矛盾 | 反思性主题分析 | 理论立场、研究者反思、解释深度、材料支撑 |
| 分析语言如何组织权力、主体位置与合法性 | 指定传统的话语分析 | 概念依据、细读证据、制度和历史语境 |
| 分析角色、情节、因果与时间组织 | 指定传统的叙事分析 | 叙事单位、结构与语境、比较和反例 |

这些路径可以组合，但须解释每一部分如何衔接。框架分析与叙事分析并非同义词；不得把词频、情感或主题模型结果直接命名为完整叙事结构。

## 3. 候选维度：作为敏感概念，不是预设答案

下列是可选的研究设计提示，不是经过验证的量表或穷尽分类。按问题选用、结合文献与试编码修订。

| 维度 | 可问的问题 | 需要区分 |
| --- | --- | --- |
| 发言与授权 | 谁说话，谁被引用，谁被赋予专业权威？ | 原发言、转述、认可、反驳 |
| AI 角色与能动性 | AI 是工具、伙伴、竞争者、基础设施还是拟人主体？ | 修辞拟人化与明确的自主性主张 |
| 行动者与利益 | 谁行动、谁受益、谁受损、谁负责？ | 文本明示与研究者推断；缺席不等于被故意压制 |
| 情节与变化 | 发生什么变化，如何从现状走向某种未来？ | 完整故事、片段叙事、仅有评价 |
| 因果组织 | 问题被归因于技术、制度、资本、使用者还是其他因素？ | 文本的因果主张与现实的因果证据 |
| 时间与必然性 | 是迫近危机、渐进变化、历史重复还是不可避免的进步？ | 确定判断、条件预测、可能性表达 |
| 价值与风险 | 效率、公平、就业、自主性、安全如何被权衡？ | 议题存在、立场方向、强调程度 |
| 行动结局 | 叙事指向采用、限制、监管、适应或拒绝？ | 明示行动建议与隐含结局 |
| 隐喻与边界 | 哪些比较让 AI 显得可理解、可信或危险？ | 隐喻、技术定义、普通描述 |

## 4. 从试编码到可用分析

选择能够覆盖来源、体裁和反例的小批材料试编码；数量依异质性与目标说明，不用固定篇数保证“饱和”。演绎代码注明理论依据，归纳代码注明出现的材料，混合路径记录两者关系。

定量内容分析的代码必须包含定义、纳入/排除规则、正例/边界例、单选或多选、缺失处理。区分“未提及”“不适用”“全文不可得”“证据不足”。冻结用于正式比较的版本；如改版，说明哪些早期材料需要重编码。

若采用独立编码一致性检验：根据编码者数、变量尺度、多标签与缺失结构选择指标（如适用的 kappa 或 Krippendorff's alpha），说明抽样、类别分布与不确定性。保留裁决前记录，不用讨论后的共识结果计算独立一致性。不要以一个统一阈值替代方法论论证。

若采用反思性主题分析：重视研究者位置、解释备忘录和主题发展，不强制固定编码本、独立一致性统计或以共识作为真实性判据。其他技能的通用检查表不能覆盖这一方法选择。参见作者方法资源：[Understanding TA](https://www.thematicanalysis.net/understanding-ta/) 与 [Editor & Reviewer Guide](https://www.thematicanalysis.net/editor-checklist/)。

## 5. AI 辅助编码与汇总

逐项核对引用与原文位置。输出原文、候选代码、简短依据、备选解释和复核状态；不要求暴露内部推理过程。无法定位的引文撤回或标记，不补写“像原文”的句子。

扩展到大规模材料前，在未用于调提示词或修订编码本的材料上人工评估；检查反讽、引述、否定、混合立场和跨语言误差。定量分类按类别报告表现，不能只报总体准确率；定性任务保留人类解释权与审计轨迹。提示词或模型变更后检查可比性。

汇总区分文章数、片段数、说话者数及计数分母；多标签比例可能超过 100%。“常见”仅针对实际样本；代表性引文不是频率证据；未出现也可能来自检索与访问限制。

# 多主体主张、AI 安全建构与叙事竞争

用于企业高管、政治人物、研究者、意见领袖、媒体和公众之间的主张建构与传播分析。以下是可调整的研究工具，不是验证量表；按任务选择字段，不将所有 AI 叙事强制编码为安全议题。一般抽样与方法质量规则沿用 [corpus-and-coding.md](corpus-and-coding.md)。

## 1. 推断对象与抽样

先区分：不同主体表述不同；存在可观察的争论／回应；某种叙事取得受众说服优势。内容差异可支持第一种判断，明确关系证据支持第二种，第三种需要受众资料。媒体提到国家竞争，不等于媒体支持竞争；安全诉求也不预设为商业包装或真实风险结论。

公开声明、演讲、访谈、个人帖子、政策文件和新闻均可提供主张证据。按事件、时期、主体职责／组织位置和渠道建立候选名单，不仅收集已被媒体引用的人。记录初始样本与关系追踪扩展样本的发现路径，不能将后者冒充代表性总体。意见领袖资格需预先说明领域、平台、指标及测量日期；没有规则时保留待判定，不仅凭名气或职业赋值。

跨国比较分别记录发言者的组织关联、发布渠道所在地、语言、受众和被评价对象的国家；不凭姓名判断国籍，不把跨国主体强塞进二元分类。按事件、主体和体裁比较，不把总体数量差异直接解释为国家制度效应。时间窗口与样本量依研究问题和试点确定，不照搬某个项目的篇数或事件数。

## 2. 编码单位与溯源

文件是采集单位；具体主体的一次主张表达为 `occurrence`，全文或讨论串为语境。一个文件可包含多位发言者，同一人也可提出互相限定的主张。每条表达保存原文、位置、时间、文档版本、发言者、编码员和复核状态。

命题可独立判断时拆分；相连的风险理由与行动建议用 `argument_group_id` 保留论证关系。重复表达保留各自 occurrence，另用人工复核的 `claim_id` 归并等义命题；条件、主体、责任或立场实质改变时不得直接合并。联合声明保留联合发言及署名信息，不复制成多个独立发言。

发言者与发布者分开：新闻里的高管引语归于高管；记者自己的判断另建表达。仅有新闻转述而无原始声明时，保留“经转述可见”，不虚构原始节点。转载可作为传播记录保留，计数时区分原创和重复。

## 3. 主体与载体字段

| 字段 | 候选取值 | 判定边界 |
| --- | --- | --- |
| 主体类型 | 企业高管／其他企业代表、政治或政府人物、科研人员、社会组织代表、记者／评论员、公众、其他；可多选 | 按发言当时身份，不从观点反推 |
| 表达时组织与角色 | 机构、任职、明确代表机构／个人观点／联合署名／未明确 | 官网发布不自动等于每句话均代表机构 |
| 意见领袖标签 | 是／否／待判定，附规则和依据 | 与职业身份可重叠；未建立规则不能赋“是”或“否” |
| 国家关联 | 国家／地区＋关联类型与依据，可多条 | 区分组织所在地、任职位置与自我认同，保留未知 |
| 发布者和渠道 | 机构／个人 ID；官方、媒体、个人账号、会议、学术发布等 | 与发言者分开，原始渠道和当前渠道分开 |
| 体裁 | 声明、报告、演讲、访谈、新闻、评论、帖子等 | 新闻与评论不混为同一总体 |
| 表达形式 | 本人直接陈述、直接引语、间接转述、发布者原创判断、未知 | 引用、认可、反驳分别判断 |

## 4. 安全建构的候选字段

纳入对损害、保护、风险责任或安全治理的实质判断，不要求出现“安全”二字。泛称“安全可靠”可标为低信息评价，不能补造风险机制。所有代码连接原文，允许多标签、其他和缺失；正式使用前补充纳排规则、边界例及理论或归纳来源。

| 字段 | 提取内容与候选分类 | 边界 |
| --- | --- | --- |
| 保护对象 | 用户、特定群体、公众、产业、国家、人类、生态等 | 与威胁来源分开 |
| 威胁来源 | 模型行为、滥用、能力扩散、权力集中、数据处理、跨国依赖、治理安排等 | 编码被声称的危险，不认定现实风险 |
| 因果解释 | X 如何导致 Y 的明确命题 | 不替发言者补全机制 |
| 责任归属 | 风险制造者、承担责任者、治理执行者 | 这些角色可能不同 |
| 治理主张 | 开放、限制、测试、审计、减速、监管、合作等，连同对象、主体与条件 | 对每项行动标支持、反对、条件性支持或仅描述 |
| 控制对象 | 能力／访问扩散、系统行为、研发／部署节奏等 | 控制权重不等于控制系统行为 |
| 正当化依据 | 技术证据、专业经验、公共利益、权利、公平、道德责任、国家安全等 | 不从身份推定理由 |
| 援引证据及可得性 | 测试、案例、研究、专家判断等；方法可得／仅结果／仅提及／未检查 | 建议测试不等于已援引测试；可得性不等于质量 |
| 确定性与限定 | 事实断言、预测、可能性、条件判断、规范要求；逐字保存范围、时点和例外 | 不将规范要求排入概率等级 |
| 道德判断 | 责任、义务、正当性、公平等及对象和方向 | 性能评价不自动等于道德评价 |

国家关联按明示内容分别记录：用国家解释能力／风险／责任、维护国家领先、跨国依赖、对手威胁、国际合作、反对零和竞赛。允许共现，注明谁在断言及其对象；提到国名只是背景时不判为国家化。不默认合成“地缘化得分”，也不把中美固定对应某类立场。

另提取叙事的行动者、事件变化、时间／因果连接和未来结局。允许完整连接、片段叙事、仅评价、无法判断，不将一个风险标签直接称为完整叙事。

## 5. 主张关系与传播变化

关系方向固定为回应／转述表达 → 被引用／回应表达；这是引用指向，绘制信息扩散时需另行说明方向。关系可多选：引用、支持、反驳、限定、重新解释；每条保存两端 ID、原文定位、时间依据与匹配状态。

匹配状态分为：明确链接／点名且定位到命题；明确回应但原命题未定位；仅语义推测。后者只能作为待核验候选，不进入确认传播关系。前后时间或措辞相似本身不能证明传播；找不到目标时保留描述及未知，不杜撰 ID。

可信配对中比较条件保留／删除／新增、确定性增强／减弱／不变／不可比、范围扩大／缩小／改换、归因变化、因果解释变化以及国家关联的延续／新增／减弱。展示两端证据；压缩或改词不自动等于失真，还需检查全文、其他来源及新信息。

新闻专用字段可包括标题／导语／正文位置、记者明确认可或质疑、多方意见并置、外部证据核验。第二位发言者不自动是独立认证；没有这些载体时填不适用，不强加新闻指标。

若研究采用率，另界定事件内、时间上可得的候选主张及媒体—时间窗口观察集合。未出现的候选主张不是 occurrence；分开记录未观察到采用与访问不足。不能据未采用推断记者看过或主动拒绝。

## 6. 缺失、验证与计数

统一区分未提及（NM）、不适用（NA）、含义／身份未知（UNK）、所需材料不可得（UNAV）。节选不足以判断全文未提及；未知不赋零。实质解释附明示／上下文推断／证据不足，保留备选解读与裁决前记录。

试编码覆盖主体、渠道、语言、直接／转述表达和反例。定量内容分析既检查命题切分，也检查字段一致性；不要以在协商好的单位上达成共识冒充独立可靠性。版本改变后明确需要重编码的材料。其他方法按自身质量标准处理，不普遍强制量化一致性。

分别汇总主体数、文件数、表达次数、去重命题数及确认关系数；多标签比例可超过 100%。高频发言／转载不等于更多主体认同，网络中心位置不等于说服力。重复主体、主张与事件带来的依赖应进入分析设计，不能把所有配对当独立样本。

## 7. 构造示例

以下仅为示范，不是实证语料。

- 高管在个人账号说：“为避免滥用，高能力模型应测试后分阶段发布。”发言者是高管，代表机构与否未知；威胁是滥用，行动有能力和测试条件。没有给出测试结果，不能编码为已经用测试证明风险。
- 新闻写：“该高管认为开放模型不安全。”保留高管归因，不赋为媒体认可；若已确认上句是对应来源，检查范围扩大和条件删除，不能在未看全文时直接宣布失真。
- 政治人物说：“我反对上述限制，共享模型能减少对外国供应商的依赖。”明确指向前述主张才建反驳边；依赖可以编码，外国威胁不能自动赋值。
- 评论者说：“两国不应把安全当竞赛，应共同审计。”编码反对竞赛和国际合作；意见领袖身份需独立规则，不能从这段评论推定。
